# KeyCadence

A gamified daily practice companion for young piano beginners (ages 6–12). The piano is the controller; the app is a coach, a timer, and an adventure map.

## Documentation

- [Product Spec v2](docs/product-spec.md) — design principles, platform and stack, onboarding assessment, the six-block session engine, gamification layer, scale roadmap, parent/teacher views, data model, build order, input layer (MIDI and microphone), and the sight-reading generator.

## Status

Pre-implementation. The spec's build order (§9) is the roadmap: the first milestone is the core loop (child profile, six-block session engine with timers, XP, daily streak with freezes, local persistence).
